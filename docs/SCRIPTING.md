# 2GameScript 2.2.1 — Documentación canónica

La documentación completa y normativa del lenguaje está en:

**`docs/2GAMESCRIPT_BIBLE.md` — Biblia de 2GameScript 2.2.1**

Ese manual reemplaza a la antigua Biblia 2.1 de este archivo y cubre de forma estructurada:

- modelo de ejecución del intérprete;
- sintaxis léxica y bloques;
- eventos estándar, señales y eventos de animación;
- valores, interpolación y rutas;
- asignaciones y comparaciones;
- Input Map;
- entidades y Prefabs;
- movimiento, física y colisiones;
- todos los componentes/clases integrados y sus propiedades;
- AnimationClip y Animator;
- FREE, BUBBLE, NOVEL y TextStyle;
- scripts de escena y capa;
- tilemaps y superficies;
- persistencia `global.*` / `save.*`;
- referencia alfabética de comandos;
- compatibilidad legacy;
- cookbook de patrones completos;
- diagnóstico de errores;
- rendimiento y diseño;
- gramática práctica EBNF;
- límites explícitos de la versión.

El mismo documento viaja dentro del JAR del Studio para el lector integrado **Ayuda → Biblia completa de 2GameScript (F1)** y además se copia como archivo legible en el distribuible Windows:

```text
manuals/2GameScript-Biblia.md
```

La referencia rápida `docs/2GAMESCRIPT_API_REFERENCE.md` sigue siendo útil como consulta corta, pero la Biblia completa es la autoridad documental de 2.2.1.
